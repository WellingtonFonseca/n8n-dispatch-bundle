# n8n dispatch: HSM carousel and image types

The HSM types that send image URLs: Carousel (2 to 10 images) and Image (one image). Both store the URLs in the `cards` column and send them as `cards`. The rest of the HSM template (list, details modal, variables) is in wiki/n8n-dispatch-templates.md. What must not break: the payload shape `cards` (the n8n Code nodes read it) and the validation of both types.

HSM type "Imagem Carrossel" (`carousel`, `HsmTemplate::TYPE_CAROUSEL`), type "Imagem" (`image`, `HsmTemplate::TYPE_IMAGE`) and `text`. The image type reuses the carousel's storage, form block, validator and payload with ONE card.

# n8n dispatch: the resend form

The modal that "Reenviar" opens on the Dispatches screen: the variables of the template with the value of the first send and an input with the value of today, and for SMS / HSM the message that will be sent. The rest of Resend (guards, what is recorded) is in wiki/n8n-dispatch-dispatches-screen.md. What must not break: a resend never goes out with an empty variable, the preview never changes what is sent, the form never calls n8n by itself.

## Traps

- Every variable the template names is required: a template that lists a name the contact never has (a field the contact lacks) cannot be resent until the user types a value in the form.
- Read the input names with attr(), never data(): data() turns `007` into 7 and the confirmed value is lost.
- A template with no variable posts no `variables`: `form=1` is what tells the server it is a form.

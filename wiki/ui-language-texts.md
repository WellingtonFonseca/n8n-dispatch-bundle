categoria: ui
regras:
- Plugin texts: `Translations/en_US` and `pt_BR`, four files each: `messages.ini` (screens), `flashes.ini` (delete refusals), `validators.ini` (validation errors) and `javascript.ini` (texts the browser scripts draw). Every key has a pt_BR text with the same placeholders; `Tests/Unit/Translations/TranslationParityTest.php` fails otherwise. Tests that check a reason use `Tests/Unit/EventListener/EnUsTranslator.php` (serves the real en_US texts of messages.ini and flashes.ini).
- Flash messages come from Translations/en_US/flashes.ini, not messages.ini.
- Texts in the browser come from `window.mauticLang` (filled from `javascript.ini` in the system language, merged over en_US); scripts keep an English fallback (`translate()` in n8ndispatch-shared.js, `labelFor()` in campaign-preview-icons.js).
- Core's own words (tab names, field labels such as "Advanced", "From name") are not ours to translate: messages that name them use core's translation keys. They are English in pt_BR until the core pack is installed.
- The core pt_BR pack is installed from `https://language-packs.mautic.com/` through Settings > Configuration. In dev it lives in `mautic/mautic/translations` (a bind mount: [../../wiki/docker-mautic5.md](../../wiki/docker-mautic5.md)). `config/local.php` must be writable by `www-data` (uid 33) or the Configuration screen cannot save (`chmod 666`, git-ignored).
- Failure reasons are translated (Service/DispatchFailureReasons, keys mautic.n8ndispatch.failure.*), every reason starting with 'N8nDispatch: ' (DispatchFailureReasons::PREFIX), translated when the step runs (the user's language on screen, the system's from cron) and stored as text. What n8n answers and exception messages pass through as they are. Monolog lines stay English. Tests compare the prefix and the `{{n}}`.
- Dates on cards follow the system language (LocaleConventions: dd/mm/yyyy HH:mm in pt_BR, mm/dd/yyyy in English, no month names, no seconds) in Mautic's local time zone; Mautic's dateToFullConcat prints English month names.
- A new or changed translation key needs `cache:clear` (and `apachectl graceful`), or the screen shows the raw key.
- Plugin icon: `Assets/img/icon.png` and an identical `Assets/img/n8ndispatch.png` (200x200, transparent; the plugin's card is an INTEGRATION card, looked up as strtolower(integration name).png by AbstractIntegration::getIcon(); a plain plugin card uses icon.png). The n8n symbol only (no wordmark), so it reads on light and dark themes. Covered by `Tests/Unit/PluginIconTest.php`.
- Table and field labels of the screens are Portuguese (Detalhes, Reenviar, Cancelar, Histórico, Sucesso / Falhou).
